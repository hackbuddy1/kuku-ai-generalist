# Kuku AI Generalist Assignment

All three problems, one folder each. Every tool runs with a free Gemini key (`GEMINI_API_KEY`) and the model can be swapped with one setting. The input pack is confidential and is not included; put the episode folder in each tool's `data/` folder to run it.

| Folder | Problem | What it does |
|---|---|---|
| `promo-finder/` | 1. Find the Promos | Reads the screenplay pack, finds and ranks 20-60 s promo clips with exact timestamps, hook, cliffhanger and quality flags |
| `ai-lawyer/` | 2. AI Lawyer (India) | Chat + voice legal helper for refunds, rent deposits and unpaid salary; cites only a verified list of laws, drafts notices, practice mode |
| `cast-sheet/` | 3. Own problem | Builds a dubbing cast sheet: resolves the many speaker labels in AI-written scripts into one voice per character |

Each folder has its own README with how it works, how to run it, and its limits. Solution docs and raw outputs are in the Drive folder.
